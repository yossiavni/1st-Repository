# Reflection AI Beam: Research Baseline

This is a research baseline for building a Beam-class open Mixture-of-Experts LLM. Sources go up to 14 Oct 2026.

- `Beam_Research_Baseline.docx`: the main Word document (21 pages). In Word, right-click the table of contents and choose *Update Field*.
- `Beam_Research_Baseline.pdf`: a PDF rendering of the same document.
- `figures/`: architecture and pipeline diagrams, benchmark charts, and the roadmap.
- `src/make_figures.py`: regenerates the figures (`python3 src/make_figures.py figures`, needs matplotlib).
- `src/build_docx.js`: rebuilds the document (`node src/build_docx.js`, needs the `docx` npm package).

Unless marked otherwise, every Beam number is reported by Reflection itself. Beam's weights were not yet published when this was written.
